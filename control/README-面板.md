# ROE 本地服务端控制台

一个只依赖标准库的控制面板，用来管 `ring-of-elysium-local` 这套服务端：启停、账户、联机、房间、全部设置。

启动方式：双击根目录的 **`启动面板.cmd`**（以窗口形式打开，无浏览器地址栏）。
面板本身是 `control/app.py`（Python 3.12，无第三方依赖），监听 `127.0.0.1:8770`。

---

## 1. 已实现的功能

### 控制台
- **一键开服**：起服务端 + 自动拉起本机客户端，客户端连 `127.0.0.1:8001`。
- **仅开服（主机）**：只起服务端，不弹客户端；绑定 `0.0.0.0` 时局域网/N2N 其他机器可连。
- **停止**：先 `CTRL_BREAK` 让服务端自己收尾，8 秒不退再 `taskkill /T /F`。
- 状态实时显示：PID、运行时长、三个端口（8001/9001/18001）、lobby/proxy/endpoint 就绪状态、事件计数。

### 客户端
- 选择 IP（自动列出本机网卡 IPv4，含 N2N/TAP 地址）+ 端口，点击启动。
- 本机可多开：每次启动的客户端由服务端**依次分配空闲账户**。
- 「全部关闭」一键结束所有客户端。

### 账户
- 添加 / 删除账户；每个账户自动派生独立的 actor UID 与外观存档目录。
- 设置「主机账户」。
- **IP → 账户绑定**：局域网里想固定某人用某个身份，就填他的 IP；没有绑定的连接按顺序轮换。
- 账户数据：`control/state/accounts.json`，存档在 `runtime/local-accounts/<name>/`。

### 组队 / 房间
- 创建房间（名称、房主账户、人数上限），加入/移除成员，列表展示成员。
- **「开启同一战局」按钮已就绪**，但后端统一战局尚未实现：点击只会把房间标记为 `starting`，不会真的把多人塞进同一局（这是你要求的「先做 UI，后端延后」）。

### 服务端设置
- **36 个启动项**，按 7 类分组：启动/剧本、世界与时间、武器与装备、战利品、靶场/机器人、联网、调试与实验。
  每项都有中文说明和对应的上游命令行参数（鼠标停在说明上可看到 `--xxx`）。
- **27 个 `config/*.json`** 的在线编辑：语法校验、保存前自动备份到 `control/state/backups/`，`wire`/`region-source` 只读。
- 「查看命令行」输出最终要执行的完整命令（dry-run，不启动）。

### 日志
- 服务端控制台输出、每个客户端输出、每局的 `endpoint/proxy/lobby/client` 日志，点开看尾部 400 行。

## 2. 联机玩法

**主机（本机）**
1. 服务器页 → 监听地址选 `0.0.0.0`，对外 IP 填本机局域网 IP（面板会自动列出，例如 `192.168.2.9` 或 N2N 的 `10.167.x.x`）。
2. 控制台 → 「仅开服（主机）」。
3. 其他机器：控制台 → 客户端 IP 填主机 IP → 「启动客户端」。

**加入方（另一台机器）**
不需要装服务端，只要有完整客户端：把 `Europa_Client.exe` 用
`-language=en -garena -uid=1 -server=<主机IP>:8001` 启动即可（面板的客户端卡片可以生成这个命令）。

> 9001 端口只监听 127.0.0.1（C# 大厅只服务本机），远程客户端走 8001，由代理转发到本机 9001，所以远程不需要 9001。

## 5. 已知限制

- **统一战局未实现**：多人目前是「多人各自在同一台服务端上玩单局」，不是同一局互相当队友（上游本身也不支持多房间/多成员场景同步）。
- **倒地/救援**：上游未实现，协议 ID 被 VMProtect 保护，面板不做假。
- **防火墙隔离**：本机三个防火墙配置是关闭的，面板启动服务端时设置 `ROE_SKIP_FIREWALL=1` 跳过上游的隔离步骤；如需隔离请打开防火墙并用管理员跑一次上游 `play.cmd`。
- **端口冲突**：8001/9001/18001 被占用时开服会失败；先「停止」再启动。
- 设置里的 `duration` 到点会结束整局（默认 2400 秒）。

## 6. 实测记录（2026-10-24）

**接口自检**：`control\selftest.py` 26 项全过（状态/设置读写/账户增删/房间/配置读写/命令预览/日志）。

**一键开服链路**：服务端三个端口全部就绪（8001 TCP / 9001 TCP / 18001 UDP），客户端自动拉起并连上大厅，
日志出现 `account_assigned` → `heartbeat_reply` / `cosmetics_issued` / `novice_notification`。

**一个必须知道的坑：窗口焦点。**
游戏窗口如果在后台（被面板/浏览器挡住或最小化），引擎会**暂停初始化**，表现就是「客户端不联网、黑屏、一直显示检查网络」。
点一下游戏窗口让它到前台，几秒内就会开始握手并进入大厅。面板启动客户端后会尝试自动前置，
但 Windows 对 `SetForegroundWindow` 有前台锁定限制，不保证成功——没反应时手动点一下即可。

**账户轮换**：默认账户 `default` + 新建的 `player2`。同一 IP（本机多开）会按连接顺序轮换，
适合两台机器各一个客户端；同一台机器双开时两个客户端可能抢到同一账户，建议配合「IP 绑定」使用。

**统一战局**：房间、成员、开始按钮都可用，但点击后只是把房间标记为 `starting`，不会真的把多人塞进同一局。

## 7. 准备时间与实时指令（2026-10-24 晚）

**准备时间**：服务器页新增「准备时间(秒)」，默认 47，映射 `--selection-seconds`，范围 1–180。
调到 10 左右开局很快；太短（<5）客户端可能来不及加载选点界面。改完点「保存并重启」。

**实时指令页**（左侧导航第 4 项）：
- 血量：满血 1000 / 半血 500 / 自定义
- 弹药：12ga(30004) / 5.56(30001) / 7.62(30002) / .45(30005)，每次 1–100
- 训练靶：造成 N 点伤害（1–1000）
- 快捷：击杀自己（0x533 终局死亡）/ 复活自己（重置血量，不是倒地）

原理：面板把动作写进 `runs/<id>/live-commands.json`（原子替换），场景端在客户端下一次上报
`0x1f49` 时取队列执行，结果写进 `endpoint.log` 的 `live_state_action` 事件，面板底部实时显示
「已执行 / 拒绝原因」。

要求：服务器页勾选「实时指令」（`--live-control`）并重启；没有运行中的局时按钮会报错。
队列上限 128 条，重启服务端清空。

## 8. 最低血量 / 人机队友（2026-10-24 晚）

**最低血量**（`--min-own-hp`，0–1000，默认 100）：写入本局 `world.json` 的 `hp_floor`。
伤害（寒流/区域/手雷/敌人）不会把血量打到该值以下；设 0 才能被打死。
实时指令面板里「设置血量」仍可手动改到更低的值。

**人机队友**（`--team-bots`，0–2）：
- 大厅组队回应改成 3 人：你 + Bot1 + Bot2（`roe_team_2022.team_body` 支持 1..3 名成员）
- 场景里用同一批 UID（`0x2040000900000/1`）生成两个被动角色，固定坐标、不动、有独立 HP
- 实现方式：把这两个 UID 写进本局 `target-roster-armored.json` 的 `passive_targets`，
  同时队伍报文里用同名 UID——这样大厅队伍和场景实体是一致的

限制：客户端是否把它们标成「队友」（蓝点/队友血条）取决于它是否按 UID 关联队伍与场景实体，
上游一直没解决这个绑定；当前至少保证「大厅 3 人 + 图里两个静止角色 + 可打、有血量」。

## 9. 双人联机（一键）

控制台新增 **「双人联机」卡片**：选对外 IP → 点「一键开服」。

它做的事：
1. 设置 `--bind-host 0.0.0.0`、`--advertise-ip <你选的 IP>`、`--coop`，并关闭人机队友
2. 账户不足 2 个时自动创建 `friend`
3. 以 coop 模式起服务端（顺便拉起本机客户端）
4. 卡片里显示朋友的启动命令：`Europa_Client.exe -language=en -garena -uid=1 -server=<IP>:8001`

coop 模式在服务端开启：场景 peer 复制（`--peer-avatar-config`）、共享地面物资（`--shared-ground-loot`）、
共享血量（`--shared-peer-health`）。因为上游限制，coop 下会自动关闭门/可破坏物和自定义战利品表。

大厅组队报文也在 coop 下共享：两个真实连接会看到彼此，队伍就是 2 人。

注意：朋友必须和你在同一个 N2N/局域网；两个客户端同时在线才会出现 2 人队伍。
