无限法则（ROE）联机助手 —— 朋友端
=====================================

一、你需要什么
1. 完整的 2022 版《无限法则》客户端（0.2.989.0）。
   助手会自动校验 Europa_Client.exe 的 SHA-256，不符会提示并拒绝启动。
2. 能和主机互通的网络：同一个局域网，或同一个 N2N（如 EasyN2N）。

二、怎么用
把「无限法则联机助手.exe」放到游戏目录里（和 Europa_Client.exe 同级），双击运行。

如果不想放进游戏目录：双击后点「浏览…」选游戏目录，助手会记住
（记在同目录的 client.txt 里，下次不用再选）。

界面上的「主机 IP」默认取同目录 server.txt 的内容（当前 10.167.31.127）。
主机换地址就改 server.txt，或者直接在界面上改。

三、点「开始游戏」之后
助手会：
1. 校验客户端版本（约 1 秒）
2. 用 -language=en -garena -uid=1 -server=IP:8001 启动游戏
3. 在日志框里显示结果

进游戏后：Esc 关掉「活动中心」→ Play → 训练模式 / 开始配对。
主机开的是双人联机模式，两人都进大厅后由一人建队，队伍上限 2 人。

四、连不上怎么查
1. 先在命令行 ping 主机 IP，确认 N2N/局域网通。
2. 确认主机面板显示「服务端运行中」，端口 8001 / 18001 已监听。
3. 你本机防火墙如果开着，允许 Europa_Client.exe 出站。
4. 还不行就把助手日志框里的文字截图发给主机。

五、说明
- 不修改游戏文件，只用命令行参数把游戏指向主机的服务端。
- 需要 Windows 自带的 .NET Framework 4.x（Win10/11 默认就有）。
- 游戏设置/缓存仍写在你的客户端目录（UserData 等），属正常现象。
